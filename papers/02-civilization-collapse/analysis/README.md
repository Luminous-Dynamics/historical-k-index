## Key Equations

### The Threshold

```
θ = C/(B+C) ≈ 0.375

Where:
B = benefit of cooperation
C = cost of cooperation

Below θ, defection is the Nash equilibrium.
```

### Cascade Dynamics

```
dH₃/dt = -λ(θ - H₃) - λ₂(θ - H₃)²

v_cascade = λ(θ - H₃)² / √R

Where:
λ = modernization factor
R = coordination redundancy
```

### Recovery Probability

```
P(recovery | H₃ < θ) ≈ 0.15 × e^(-0.05 × years_below_θ)

After 10 years below threshold: P ≈ 9%
After 20 years below threshold: P ≈ 5.5%
```

### AI Amplification

```
dH₃/dt_AI = dH₃/dt × (1 + A_positive)
dλ/dt_AI = dλ/dt × (1 + A_negative)

If A_negative > A_positive: Accelerates toward threshold
If A_positive > A_negative: Accelerates toward safety
```

### Technology Evaluation

```
Coordination_Score = ΔH₃ - α × Δλ

Where α ≈ 0.5

Score > 0.3: Deploy aggressively
Score < -0.3: Restrict or prohibit
```
