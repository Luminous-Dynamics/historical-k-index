## Revolutionary Extension 2: The Coordination Contagion

### Core Insight
Coordination spreads like a disease. Trust begets trust. Cooperation enables cooperation. Defection triggers defection.

### Epidemiological Model
$$\frac{dK_i}{dt} = \beta \sum_j A_{ij} K_j (K_{max} - K_i) - \gamma K_i + \eta_i$$

Where:
- $A_{ij}$ = Network adjacency (trade, treaties, communication)
- $\beta$ = Contagion rate (how fast cooperation spreads)
- $\gamma$ = Decay rate (how fast trust erodes without reinforcement)
- $\eta_i$ = Exogenous shocks

### Key Predictions
1. **Coordination Clusters**: High-K nations cluster geographically/politically
2. **Super-spreaders**: Some nations disproportionately affect global K
3. **Herd Immunity**: Above ~70% high-K nations, collapse becomes self-limiting
4. **Vaccination**: Strategic interventions in key nodes prevent cascades
